# hinnkaDE-Remake
An remake of hinnkaDE for Arch Linux with better performance improvement and customization

You can edit it how ever you want!

---------

# Packages

The list of packages is:


`brave-bin` / `feh` / `flatpak` / `fastfetch` / `flameshot` / `lxpanel` / `openbox` / `polybar` / `vlc`


# Start install

To install it, Get shell file on release
